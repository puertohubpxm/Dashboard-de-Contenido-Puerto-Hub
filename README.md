# Puerto Hub · Content Dashboard

Panel de contenido para el negocio de creador **@puertohub.pxm**: biblioteca
de hooks, analíticas, seguimiento de competidores, programador
multiplataforma, calendario de contenido y tendencias de IA.

Construido con **Next.js + Tailwind CSS + shadcn/ui**, modo oscuro con
acentos terracota.

## Empezar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run start` — sirve el build
- `npm run lint` — ESLint
